# Первый запуск PullApps на macOS

PullApps распространяется вне Mac App Store. Текущие релизы имеют целостную
ad-hoc подпись, но пока не подписаны платным сертификатом Developer ID и не
нотарифицированы Apple. Поэтому при первом запуске macOS может показать:

> Apple не удалось подтвердить, что файл «PullApps» не содержит вредоносного ПО.

Это предупреждение Gatekeeper, а не результат обнаружения вируса. Разрешайте
запуск только если приложение скачано из официального репозитория и контрольная
сумма совпадает.

## 1. Скачать официальный релиз

Откройте страницу [Releases](https://github.com/Ch1kez/PullApps/releases/latest)
и скачайте два файла одной версии:

- `PullApps-vX.Y.Z-macos-universal.zip`;
- `PullApps-vX.Y.Z-macos-universal.zip.sha256`.

Не скачивайте PullApps или IPA-файлы из Telegram, с файлообменников и из
неизвестных репозиториев.

## 2. Проверить SHA-256

Положите ZIP и файл `.sha256` в одну папку. В Терминале перейдите в неё, например:

```bash
cd ~/Downloads
shasum -a 256 -c PullApps-vX.Y.Z-macos-universal.zip.sha256
```

Вместо `X.Y.Z` укажите скачанную версию. Нормальный результат:

```text
PullApps-vX.Y.Z-macos-universal.zip: OK
```

Если показано `FAILED`, не открывайте архив: удалите оба файла и скачайте их
заново со страницы Releases.

## 3. Установить приложение

1. Распакуйте ZIP обычным двойным нажатием в Finder.
2. Перетащите `PullApps.app` в папку `/Applications` («Программы»).
3. Попробуйте открыть PullApps один раз.
4. В предупреждении macOS нажмите «Готово» или «Отмена» — название кнопки
   зависит от версии системы.

## 4. Разрешить запуск только для PullApps

1. Откройте меню Apple → **Системные настройки**.
2. Выберите **Конфиденциальность и безопасность**.
3. Прокрутите страницу до раздела **Безопасность**.
4. Найдите сообщение о заблокированном PullApps и нажмите **Всё равно открыть**.
5. Подтвердите действие паролем пользователя или Touch ID.
6. В последнем диалоге нажмите **Открыть**.

Кнопка доступна примерно в течение часа после неудачной попытки запуска. Если
её нет, снова попробуйте открыть PullApps и вернитесь в настройки. После
подтверждения macOS запомнит исключение для этого приложения, и следующие
запуски будут выполняться обычным двойным нажатием.

Официальные инструкции Apple:

- [Открытие приложения от неизвестного разработчика](https://support.apple.com/ru-ru/guide/mac-help/-mh40616/mac);
- [Безопасное открытие приложений на Mac](https://support.apple.com/ru-ru/102445).

На Mac, которым управляет организация, кнопка может быть отключена политикой
администратора. В таком случае обратитесь в свою ИТ-службу — обходить управление
устройством не следует.

## Чего делать не нужно

Не отключайте защиту macOS целиком и не запускайте команды наподобие:

```text
sudo spctl --master-disable
xattr -cr /Applications/PullApps.app
```

Системный способ «Всё равно открыть» создаёт точечное исключение для выбранного
приложения и не ослабляет Gatekeeper для всех последующих загрузок.

## Если сообщение говорит, что приложение повреждено

Сообщение «приложение повреждено» или предложение немедленно переместить его в
корзину не следует игнорировать. Убедитесь, что скачан последний релиз, и снова
проверьте SHA-256. Если сумма совпадает, но ошибка повторяется, создайте
[issue](https://github.com/Ch1kez/PullApps/issues/new) и укажите:

- версию PullApps;
- модель Mac и версию macOS;
- точный текст сообщения;
- результат команды `shasum`.

Не прикладывайте Apple ID, DSID, UDID, cookie, пароль и код 2FA.

## Почему предупреждение пока появляется

Чтобы Gatekeeper доверял приложению без ручного исключения, разработчику нужно
участвовать в Apple Developer Program, подписывать сборку сертификатом
**Developer ID Application**, включить hardened runtime и отправлять релиз в
службу нотарификации Apple. После успешной проверки notarization ticket
прикрепляется к приложению.

Материалы для разработчиков:

- [Signing Mac Software with Developer ID](https://developer.apple.com/developer-id/);
- [Notarizing macOS software before distribution](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution);
- [Создание сертификатов Developer ID](https://developer.apple.com/help/account/certificates/create-developer-id-certificates).
