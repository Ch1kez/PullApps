# Участие в разработке

Спасибо за интерес к PullApps. Перед крупным изменением лучше сначала открыть
issue и описать предлагаемый сценарий.

## Локальная проверка

```bash
cd frontend
npm ci
npm run build
cd ..
go test ./...
go vet ./...
```

Для запуска интерфейса установите Wails v2.16.0 и выполните `wails dev`.

## Требования к изменениям

- Не добавляйте Apple ID, DSID, UDID, cookie, токены, пароли, коды 2FA и IPA.
- Не ослабляйте права доступа к Keychain и файлам сессий.
- Для новой логики добавляйте тесты, если это возможно.
- Документация проекта ведётся на русском языке.
- Перед pull request убедитесь, что команды проверки выше проходят.

Сообщения об уязвимостях отправляйте по инструкции из [SECURITY.md](SECURITY.md),
а не через публичный issue.
